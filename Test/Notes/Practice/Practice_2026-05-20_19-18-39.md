## SOLUTION KEY

<details>
<summary>Click to reveal answers</summary>

#### Q1
- **Answer:** `TradeAnalyzer tradeAnalyzer = new TradeAnalyzer(); double result = tradeAnalyzer.analyzeTrade(1000.0);`
- **Explanation:** Step 1: We need to create an object 'tradeAnalyzer' of the class 'TradeAnalyzer'. This is done using the syntax 'TradeAnalyzer tradeAnalyzer = new TradeAnalyzer();'. Step 2: We then call the 'analyzeTrade' method on this object, passing '1000.0' as the trade value. The syntax for this is 'double result = tradeAnalyzer.analyzeTrade(1000.0);'.

#### Q2
- **Answer:** `class, objects`
- **Explanation:** A class in Java is defined using the 'class' keyword. It serves as a template for creating objects, which are instances of the class.

#### Q3
- **Answer:** `objects, public`
- **Explanation:** In Java, a program is viewed as a collection of objects that meet specific requirements and interact with each other through publicly made functionalities.

#### Q4
- **Answer:** `Correct explanation.`
- **Explanation:** This question tests the understanding of core concepts in Class Definition, including the definition of a class, object, class definition, and the class keyword in Java. A correct match demonstrates a clear grasp of these fundamental Object Oriented Programming terms.

#### Q5
- **Answer:** `A`
- **Explanation:** This question tests the understanding of the fundamental concept of Object-Oriented Programming (OOP) that a class defines a new data type and is a template for creating objects, while an object is an instance of a class.

#### Q6
- **Answer:** `B`
- **Explanation:** This question assesses the understanding of Java programming basics, specifically that the name of the public class must coincide with that of the file.

#### Q7
- **Answer:** `Define a class with attributes and methods, Create objects from the class template, Use the class to model different government expenditures`
- **Explanation:** The OOP concept that allows defining a blueprint for objects is a class. A class is a template for an object, and an object is an instance of a class. By defining a class with attributes and methods, the architect can create objects that represent different types of government expenditures, such as infrastructure spending or social welfare programs.

#### Q8
- **Answer:** `A class definition for 'MonetaryPolicy' could be: public class MonetaryPolicy { private String policyName; private double interestRate; public MonetaryPolicy(String policyName, double interestRate) { this.policyName = policyName; this.interestRate = interestRate; } public void updateInterestRate(double newInterestRate) { this.interestRate = newInterestRate; } public void displayPolicyDetails() { System.out.println("Policy Name: " + policyName); System.out.println("Interest Rate: " + interestRate); } }`
- **Explanation:** This question requires the student to apply the concept of class definition to a real-world scenario in central banking and monetary policy. The correct answer demonstrates an understanding of class structure, including fields and methods, and how they are used to create a class that can manage monetary policy data.

#### Q9
- **Answer:** `True`
- **Explanation:** According to the source, 'The name of the class coincides with that of the file' and 'Class name must be the same as the file name where the class lives'.

#### Q10
- **Answer:** `False`
- **Explanation:** The source states that 'A program can contain one or more class definitions but only one public class definition'.

#### Q11
- **Answer:** `import figure.Rectangle; import figure.Circle; or import figure.*; (assuming Rectangle and Circle are in the 'figure' package)`
- **Explanation:** To use classes from another package, we need to import them. We can import each class individually (e.g., import figure.Rectangle; import figure.Circle;) or import all classes in the package at once (e.g., import figure.*;). This allows us to create objects of those classes in our current class, 'TestFigures'.
