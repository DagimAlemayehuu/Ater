#### Q1
- **Answer:** `500.0`
- **Explanation:** The method invocation 'calculateExportValue(100, 5)' passes '100' as the unitPrice and '5' as the quantity. The method definition 'public double calculateExportValue(double unitPrice, int quantity) { return unitPrice * quantity; }' multiplies these two values and returns the result. Therefore, the return value is 100 * 5 = 500.0.

#### Q2
- **Answer:** `different parameters, same method name`
- **Explanation:** Method overloading allows multiple methods with the same name to be defined, but with different parameter lists. This is useful in International Trade Analysis, where different tariff calculations may be required based on different factors.

#### Q3
- **Answer:** `local variable`
- **Explanation:** A local variable is a variable that is declared within a method and can only be accessed within that method. This is useful in International Trade Analysis, where temporary results may need to be stored and used within a specific calculation.

#### Q4
- **Answer:** `Correct explanation.`
- **Explanation:** This question tests the student's understanding of key Object Oriented Programming concepts and their application in a market strategy context. The correct matches demonstrate an understanding of how packages organize related classes, polymorphism enables flexibility, instance variables store object-specific data, and object references enable interaction with objects.

#### Q5
- **Answer:** `A`
- **Explanation:** Instance variables are initialized with default values when an object is created, unless explicitly initialized through a constructor or other means.

#### Q6
- **Answer:** `B`
- **Explanation:** A static variable is shared by all objects of the class, meaning changes made by one object affect all others.

#### Q7
- **Answer:** `Declare a package for data collection with a specific name, Create a class for data collection with a protected access modifier, Import the data collection package in the econometric analysis package`
- **Explanation:** To structure the project effectively, the researcher should first declare a package for data collection with a specific name (Step 1). Then, they should create a class for data collection with a protected access modifier to control access to the class (Step 2). Finally, they should import the data collection package in the econometric analysis package to use the data collection class (Step 3).

#### Q8
- **Answer:** `We can define a base class called 'MonetaryPolicy' with subclasses 'InterestRatePolicy' and 'MoneySupplyPolicy'. The base class can have public methods for setting and getting policy parameters, and the subclasses can extend these methods. To ensure efficient memory management, we can rely on Java's garbage collection mechanism to automatically reclaim memory when objects are no longer needed. The class definition should include relevant attributes and methods for each policy type, and we should use public access modifiers to allow access to these members from other parts of the program.`
- **Explanation:** This question requires the application of object-oriented programming concepts to a real-world scenario in central banking and monetary policy. The student needs to demonstrate an understanding of class structure, inheritance, and memory management in Java.

#### Q9
- **Answer:** `True`
- **Explanation:** The 'public' access modifier in object-oriented programming allows access from any class, making it a fundamental concept in encapsulation and data hiding.

#### Q10
- **Answer:** `True`
- **Explanation:** Garbage collection is a critical process in object-oriented programming that automatically reclaims memory occupied by objects that are no longer needed, preventing memory leaks and ensuring efficient memory usage.

#### Q11
- **Answer:** `By directly calling the method using the class name, i.e., 'Taxation.calculateTaxRate()', since both classes are in the same package and the method is public.`
- **Explanation:** In Java, when two classes are in the same package, they can access each other's public members directly without needing to import or use the package name. This is a fundamental concept in Object-Oriented Programming (OOP) and package management in Java.
