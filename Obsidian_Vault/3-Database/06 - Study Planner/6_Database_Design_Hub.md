# 6 Database Design Hub

## Overview
The Database Design Hub revolves around SQL, a language used for describing database schema and operations on tables. SQL comprises sublanguages, including DDL, DML, DCL, and TCL, which facilitate various database operations. DDL is specifically used for creating, modifying, and deleting database schema elements, such as tables, through commands like CREATE, ALTER, and DROP. 

The creation of tables involves specifying attributes, data types, and constraints, such as primary and foreign keys, to ensure data integrity. SQL data types, including CHAR, VARCHAR, INTEGER, FLOAT, and DATE, are used to define the characteristics of attributes. The system catalog, a table that describes database objects, plays a crucial role in managing database schema. 

SQL also enables data manipulation through INSERT, UPDATE, and DELETE operations, as well as querying through SELECT statements. SELECT queries can be simple or complex, involving set operations, nested queries, and aggregate functions like COUNT, SUM, MAX, MIN, and AVG. The HAVING-clause is used to specify conditions on groups of tuples, while aliases, qualified attribute names, and the DISTINCT keyword help to ensure precise and efficient querying. Overall, the Database Design Hub provides a comprehensive framework for designing, implementing, and managing databases using SQL.
