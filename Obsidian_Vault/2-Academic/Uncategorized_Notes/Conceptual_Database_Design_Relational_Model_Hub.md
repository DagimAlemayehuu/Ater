# Overview
The Conceptual Database Design - Relational Model unit provides an in-depth examination of the principles and practices involved in designing databases using the Entity-Relationship (ER) model. This unit covers the database development methodology, phases of database design, and the application of ER modeling in database design. Students will learn to identify entities, attributes, and relationships, and develop ER diagrams to represent the conceptual structure of a database.

# Learning Objectives
* Understand the database development methodology and its phases.
* Learn to apply Entity-Relationship (ER) modeling in database design.
* Identify and define entities, attributes, and relationships in a database.
* Develop ER diagrams to represent the conceptual structure of a database.
* Analyze and apply structural constraints, including multiplicity, cardinality, and participation.
