# Definition & Mechanics
An **Information System (IS)** is a set of resources that enable the collection, management, control, and dissemination of information throughout an organization. A database is a fundamental component of an IS.

* **Key components**: 
  - **Hardware**: computers, storage devices, and network infrastructure
  - **Software**: operating systems, database management systems, and applications
  - **Data**: the information stored and processed
  - **People**: users, administrators, and developers
* **Primary goal**: support organizational operations and decision-making

# Worked Example
Domain: Film production company

| Component | Description | Example |
| --- | --- | --- |
| Hardware | Computers, storage | Servers for editing, storage for movie files |
| Software | Database, editing tools | DBMS for film metadata, video editing software |
| Data | Film metadata, crew information | Title, director, cast, shooting locations |
| People | Producers, directors, DBAs | Production team, database administrators |

The film production company uses an IS to manage film projects, track crew assignments, and store movie files.

# Edge Case
> **Q:** A university library uses a system to manage book catalogs, member information, and borrowing records. Is this system an Information System?
> **A:** Yes. The library system collects, manages, and disseminates information about books, members, and borrowing activities, supporting the library's operations and decision-making.
