## 1. Mental Model

A sequence notation can be thought of as a library catalog system, where each book represents a term in the sequence. Just as a library catalog uses a unique identifier, such as a book's title or catalog number, to locate a specific book, a sequence notation uses an index, typically denoted as $n$, to identify a specific term $a_n$ in the sequence. This analogy maps the structural components of sequence notation, such as the index and term, to the components of a library catalog system.

## 2. Formal Definition & Structural Trace

A sequence is defined as a [[Sequence_Definition]] function that assigns a unique value to each index, often denoted as $n$. The notation $\{a_n\}_{n \geq 1}$ or simply $\{a_n\}$ represents a sequence, where $a_n$ denotes the $n$-th term of the sequence, following a [[Sequence_Notation]]. A [[Recursive_Definition]] can be used to define a sequence, which leads to a [[Recurrence_Relation_Definition]]. For instance, a [[Linear_Recurrence_Relation]] of the form $a_n = c_1a_{n-1} + c_2a_{n-2}$ can be solved using the [[Characteristic_Equation]]. The solution to this equation yields the [[General_Solution]], from which a [[Unique_Solution]] can be determined with initial conditions.

## 3. Boundary Cases & Counterexamples

When dealing with sequence notation, boundary cases arise when the index $n$ approaches its limits, such as $n=1$ or as $n$ approaches infinity. A flawed step in calculating a term, such as misinterpreting the index or incorrectly applying a [[Recurrence_Relation_Definition]], can lead to an incorrect formula. For example, incorrectly solving a [[Second_Order_Linear_Homogeneous_Recurrence_Relation]] can result in an incorrect [[General_Solution]], highlighting the importance of accurately applying sequence notation and [[Solving_Linear_Homogeneous_Recurrence_Relations]]. Moreover, sequences defined by a [[Non_Homogeneous_Linear_Recurrence_Relation]] require special care to account for the non-homogeneous term.

### Recurrence Unrolling Table

Given the recurrence relation: $a_n = 2a_{n-1} + 3$, with initial condition $a_0 = 1$.

| $n$ | $a_n$ | $a_{n-1}$ | $2a_{n-1}$ | $2a_{n-1} + 3$ |
| --- | --- | --- | --- | --- |
| 0   | 1     | -       | -       | -           |
| 1   | 5     | 1       | 2       | 2*1 + 3 = 5 |
| 2   | 13    | 5       | 10      | 2*5 + 3 = 13|
| 3   | 29    | 13      | 26      | 2*13 + 3 = 29|

The recurrence unrolling table represents the step-by-step calculation of the sequence terms using the given recurrence relation. Each row corresponds to a specific term in the sequence, with columns showing the term index $n$, the term value $a_n$, the previous term value $a_{n-1}$, twice the previous term value $2a_{n-1}$, and the final calculation of $a_n$ using the recurrence relation.

## 5. Walkthrough

1. **Initial Condition**: Start with the initial condition $a_0 = 1$. This provides the base case for the recurrence relation.
2. **Calculate $a_1$**: To find $a_1$, substitute $n = 1$ into the recurrence relation: $a_1 = 2a_0 + 3$. Since $a_0 = 1$, we have $a_1 = 2*1 + 3 = 5$.
3. **Calculate $a_2$**: For $a_2$, substitute $n = 2$: $a_2 = 2a_1 + 3$. Since $a_1 = 5$, we get $a_2 = 2*5 + 3 = 13$.
4. **Calculate $a_3$**: For $a_3$, substitute $n = 3$: $a_3 = 2a_2 + 3$. Since $a_2 = 13$, we find $a_3 = 2*13 + 3 = 29$.
5. **Verify the Table**: Verify that each term in the recurrence unrolling table matches the calculations: $a_0 = 1$, $a_1 = 5$, $a_2 = 13$, and $a_3 = 29$.
6. **Conclusion**: The recurrence unrolling table accurately represents the sequence generated by the given recurrence relation and initial condition, demonstrating how each term is calculated from the preceding term.
