# 5 Modular Programming Hub - L1 Session

### Q1 [mcq]: What is the purpose of using braces in C++?
- **A)** To group statements together
- **B)** To define the scope of variables
- **C)** To indicate the start and end of a loop
- **D)** All of the above

***

### Q2 [mcq]: What is the effect of using a single brace in C++?
- **A)** It will cause a compilation error
- **B)** It will have no effect
- **C)** It will start a new block of code
- **D)** It will end the current block of code

***

### Q3 [mcq]: What is the purpose of using nested braces in C++?
- **A)** To define a function
- **B)** To define a loop
- **C)** To define a block of code within another block
- **D)** To define a class

***

### Q4 [mcq]: What happens if a brace is missing in C++?
- **A)** The program will compile but run incorrectly
- **B)** The program will not compile
- **C)** The program will run but produce unexpected results
- **D)** The program will crash

***

### Q5 [mcq]: What is the purpose of using braces to define a function in C++?
- **A)** To define the function name
- **B)** To define the function parameters
- **C)** To define the function body
- **D)** To define the function return type
