## 2026-07-05 - Path Traversal via Direct Path Concatenation and Fallbacks
**Vulnerability:** In `apps/api/src/api/routers/ai.py` within `explain_question` endpoint, `note_path` was resolved insecurely using `resolved_p = Path(secrets.vault_path) / note_path if not Path(note_path).is_absolute() else Path(note_path)`. This would allow absolute paths (e.g., `/etc/passwd`) to bypass vault containment or relative path directory traversal (`../`) to escape it.
**Learning:** Checking for `.is_absolute()` on user-supplied paths and using them verbatim if true bypasses intended root directory containment. Using standard path concatenation `/` doesn't protect against `../` path traversal either.
**Prevention:** Always use `src.utils.vault_path.resolve_vault_path` (or similar standard containment functions) and verify containment explicitly when combining user paths with a base path. Ensure to handle the potential `ValueError` raised by such helpers and return a safe `HTTPException`.
