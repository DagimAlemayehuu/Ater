Here's everything you need to go from zero to studying with Ater in under 10 minutes.

## Before You Start — Get Approved
* **DM/message Dagim** your email if you haven't signed up yet.
* Dagim approves accounts manually — you cannot log in until approved.
* Once approved, you'll get an email or message from Dagim with a link.

## Download the Right File
Latest releases can be found here: [Ater Releases](https://github.com/DagimAlemayehuu/Ater_Releases/releases/latest)

| Your machine | Download |
| :--- | :--- |
| MacBook with M1/M2/M3/M4 chip | `Ater_aarch64.dmg` |
| Windows PC (64-bit) | `Ater_setup.exe` |
| Linux (Ubuntu/Debian) | `Ater_*.AppImage` or `Ater_*.deb` |

> **Note:** Intel Macs are NOT supported in v0.2.

## Install on macOS (most people)
1. Open the `.dmg` — drag **Ater** to **Applications**.
2. **DO NOT** double-click to open yet.
3. Go to **Applications**, **right-click Ater** → click **Open**.
4. A popup appears saying "unidentified developer" — click **Open** (this is safe, this is us).
5. If you don't see "Open" in the popup: go to **System Settings** → **Privacy & Security** → scroll down → click **'Open Anyway'** next to Ater.
6. You only have to do this bypass once. After that, Ater opens normally.

## Install on Windows
1. Run `Ater_setup.exe`.
2. If **Windows SmartScreen** appears: click **'More info'** → **'Run anyway'**.
3. Follow the installer steps.

## Install on Linux
```bash
chmod +x Ater_*.AppImage
./Ater_*.AppImage
```

## First Login
1. Open **Ater**.
2. Sign in with the same email Dagim approved.
3. The app will show a **'binding device'** step — this is normal, just wait 2-3 seconds.
4. You're in!

## Pick Your Vault Folder
1. On first run, Ater asks where to store your notes.
2. Create a folder somewhere easy: e.g., `Documents/AterVault` or `Desktop/AterNotes`.
3. Click **Select Folder**.
4. This is where all your generated notes will live as markdown files (compatible with Obsidian if you use it).

## Generate Notes from Your PDFs
1. In the sidebar, click **Ater Architect**.
2. Upload your lecture PDF or paste notes/text.
3. Select your course and chapter name.
4. Hit **Generate** — it takes 1–3 minutes.
5. Done — your notes are in the vault.

## Review & Study
1. Click **Practice** in the sidebar.
2. Pick a course/chapter.
3. Answer questions — the app uses spaced repetition to quiz you on what you're weakest at.
4. If a **'Cognitive Lock'** appears, just explain the concept in your own words to unlock.

## Getting Updates
Ater updates itself. Check **Settings** → **Updates**. Click **'Check for updates'** or wait for the automatic prompt.

## Something Broke?

| Problem | Fix |
| :--- | :--- |
| App won't open on Mac | Do the right-click → Open trick (see Install section) |
| 'Engine Failure' screen | Close Ater completely, reopen it |
| Can't log in / 'Not Approved' | Message Dagim — your account might not be approved yet |
| 'Device already registered' | Message Dagim to reset your device |
| Notes not generating | Check internet connection |
| App is stuck loading | Force quit and reopen |
