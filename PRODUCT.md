# Product

## Register

product

## Users
Academic students, professional software engineers, and rigorous self-learners seeking to master complex technical concepts (CS, Mathematics, Economics) using high-fidelity Obsidian atomic learning notebooks.

## Product Purpose
A Tauri-powered desktop application built with React, Supabase, and Monaco Editor. The application ingests academic source material and structures it into beautiful, perfectly pedagogical Obsidian atomic notes featuring continuous technical prose, mathematical LaTeX formulas, interactive quizzes, dynamic force-graphs, and Mermaid logical diagrams.

## Brand Personality
* Precise
* Surgical
* Academic-grade

## Anti-references
* Cliché SaaS marketing landing pages (purple-to-blue gradients, over-rounded shapes)
* Low-density, bloated dashboard designs with nested cards
* Playful or generic "coffee-shop" learning themes

## Design Principles
1. **The UI is a Scientific Instrument**: Visual hierarchy, layouts, and spacing should feel like a premium laboratory console.
2. **Extreme Information Density**: Maximize typography legibility to present dense technical documentation, code snippets, and mathematical formulas cleanly without visual clutter.
3. **Structured Flow**: Interactions must follow a strict, predictable cadence (e.g., Monaco code entry, instant AST validation reports, structured quiz results).

## Accessibility & Inclusion
* Full WCAG AAA color contrast compliance for code blocks and LaTeX math elements.
* Accessible keyboard nav patterns for Monaco, Radix dialogs, and interactive quiz elements.
* Stutter-free rendering and support for reduced-motion options on dynamic force-graphs and charts.
