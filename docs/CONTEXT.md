## 1. Domain Terms

| Term | Canonical Definition | Evidence (Code / System References) |
|---|---|---|
| **Ater** | The product name. A local-first Personal Intelligence Operating System for academic knowledge ingestion and spaced repetition. Never referred to as "the app" or "the tool" in specs. | Configured as `productName: "Ater"` in `apps/desktop/src-tauri/tauri.conf.json:L3`. Note generation rules are governed by `Ater.md` at the project root. |
| **Atomic Note** | A single-concept Obsidian markdown file generated by Ater. Follows the 4-section structure defined in `Ater.md`. The atomic unit of the learning system. | Compiled via `_compile_pq_note` in `apps/api/src/domains/ater/service.py:L4019` and written via `create_obsidian_file` in `apps/desktop/src-tauri/src/commands.rs:L1024`. |
| **Obsidian Vault** | The local directory on the user's machine where Atomic Notes are stored. Ater reads and writes to it via Tauri IPC. Never referred to as "the folder" or "the database." | Loaded from store as `obsidianVaultPath` in `apps/desktop/src/lib/sidecarApi.ts:L1301` and resolved in Tauri backend via `get_vault_path` in `apps/desktop/src-tauri/src/commands.rs:L931`. |
| **Ater Architect** | The note ingestion workflow within the desktop client. Accepts source material, sends it to the sidecar, and displays generation progress. | Implemented in the ingestion interface of `apps/desktop/src/routes/academic.tsx`. |
| **Active Recall Engine** | The practice canvas. Supports 13 question modalities and tracks user execution performance. | Implemented in `apps/desktop/src/routes/practice.tsx`, calling `generatePractice` and `logPracticeAttempt` in `apps/desktop/src/lib/sidecarApi.ts:L683`. |
| **Cognitive Lock** | The Feynman Challenge overlay that blocks progression when FSRS retrievability drops below 70%. A core safety mechanism, not a UI feature. | Governed in the review loop of `apps/desktop/src/routes/practice.tsx`, utilizing `srs_feynman_validate` in `apps/desktop/src-tauri/src/commands.rs:L1931` and `validate_feynman_gate` in `apps/api/src/domains/ater/srs.py:L151`. |
| **FastAPI Sidecar** | The Python process (`apps/api`) spawned by Tauri. Handles all ML inference, RAG indexing, and background service loops. Couples to the desktop client lifecycle. | Spawned and managed via virtualenv Python or `uv` in `apps/desktop/src-tauri/src/lib.rs:L278` (debug) and via `ater-api` external binary in `L389` (release). |
| **ONNX Runtime** | The local embedding engine used by the sidecar for offline semantic search. Must never be replaced with a cloud embedding API without an ADR. | Embedded model files located in `apps/api/onnx_model/`, loaded via `initialize_database` in `apps/desktop/src-tauri/src/commands.rs:L143` and queried in `apps/api/src/domains/ater/embeddings_linker.py`. |

| **ater.db** | The local SQLite database. Stores FSRS ratings, note stability metrics, and vector indices. Ephemeral per-machine - not the source of truth for profiles or billing. | SQLite connection initialized in `apps/desktop/src-tauri/src/db.rs` and populated in the sidecar via `SRSEngine` in `apps/api/src/domains/ater/srs.py:L83`. |
| **Supabase** | The remote PostgreSQL database. Source of truth for user profiles, DRM locks, hardware blacklists, and billing credits. | Configured in `apps/desktop/src/lib/supabase.ts` and synced during online access via `checkOnlineLockout` in `apps/desktop/src/context/securityStore.ts:L65`. |
| **DRM Lock** | The hardware fingerprint binding system. `profiles.machine_id` in Supabase is bound to the host system's hardware ID on first activation. | Machine ID generated in Rust via `get_machine_id` in `apps/desktop/src-tauri/src/lib.rs:L165` and validated during activation checks in `apps/desktop/src/context/securityStore.ts:L185`. |
| **Hardware Blacklist** | The list of permanently banned device signatures that blocks profile activation. | Implemented via the `public.hardware_blacklist` table and database trigger function `check_hardware_blacklist` in `drm_lockout_system.sql`. |
| **PageGuard** | The React component that wraps protected routes and intercepts rendering if the security store reports unauthorized status. | Implemented in `apps/desktop/src/components/PageGuard.tsx` and wrapped around routes in `apps/desktop/src/App.tsx:L147`. |
| **MetaScannerAgent** | The pre-analysis pass in the ingestion pipeline that detects the primary academic domain of the source material before note generation begins. | Implemented as part of the ingestion agents pipeline in `apps/api/src/domains/ater/agents.py`. |
| **TokenGovernor** | The rate-limiting module in the sidecar that regulates parallel batch generation to avoid Gemini API quota exhaustion. | Implemented in `apps/api/src/domains/ater/governor.py`. |
| **Hub** | An Obsidian file that aggregates wikilinks to a group of Atomic Notes within a unit. | Referenced in note frontmatter as `hub: "[[Unit_X_Hub]]"`. | **Obsidian Force-Graph** | The interactive visualization of note relationships within the vault. | Dispatched from frontend and resolved via the Tauri command `get_vault_graph` in `apps/desktop/src-tauri/src/commands.rs:L544` and sidecar endpoint `GET /vault/graph` in `apps/api/src/domains/obsidian/router.py:L923`. |

## 2. Key Invariants

These are non-negotiable constraints. No ADR can override them. Any spec that contradicts an invariant is invalid.

1. **Offline-First**: All core Ater functions (note reading, FSRS review, practice) must work with no internet connection. Cloud calls are strictly limited to: Gemini API (generation), Supabase (auth/profile sync), and billing gateway execution.
2. **Local ML Only**: Embedding generation must use the local ONNX runtime. Cloud embedding APIs are forbidden without an explicit ADR approved by Hermes.
3. **No Purple/Violet**: The color palette defined in `docs/DESIGN.md` is immutable. Violet, purple, and indigo are banned from the UI. No exceptions.
4. **Uniform Font**: The Outfit font is the only typeface in the desktop client. No secondary fonts are to be introduced.
5. **4-Section Note Contract**: Atomic Notes generated by Ater must follow the 4-section structure (`Mental Model`, domain `h1`, domain `h2`, `The Proving Grounds`). This is defined in `Ater.md` at the project root. That file must never be moved or modified.
6. **Zero Bullet Points in Prose**: Sections 1, 2, and 3 of an Atomic Note use continuous analytical paragraphs only. Bullet points in prose are forbidden.
7. **Service Role for Admin Ops**: Profile state transitions (role, approval, credits, feature locks) are only permitted via Supabase `service_role` or an authenticated Admin profile. Client-side API calls attempting these mutations will be rejected by the RLS trigger.

## 3. Canonical Naming Conventions

| Pattern | Correct | Wrong |
|---|---|---|
| Obsidian note filenames | `Title_Case_With_Underscores` | `title-case`, `camelCase` |
| Wikilinks | `[[Concept_Name]]` | `[[concept name]]`, `[[concept-name]]` |
| YAML wikilink values | `"[[Concept_Name]]"` (double-quoted) | `[[Concept_Name]]` (unquoted) |
| Plain-text YAML fields | `course: Computer Science II` | `course: "[[Computer Science II]]"` |
| OpenSpec change paths | `openspec/changes/<change-slug>/` | `docs/Specs/<feature>.md`, root-level `spec.md` |
| Durable decision records | `docs/DECISIONS.md` entries named `ADR-NNNN: Short Title` | scattered `decision.md`, `adr1.md`, nested ADR folders |
| Sprint tasks format | `- [ ]`, `- [/]`, `- [x]` | `TODO`, `DONE`, `IN PROGRESS` |
| Tauri IPC commands | `snake_case` (e.g., `get_machine_id`) | `camelCase`, `kebab-case` |
| FastAPI endpoints | `/api/<resource>/<action>` (e.g., `/api/academics/dashboard`) | `/getAcademicsDashboard` |
| Supabase table names | `snake_case` (e.g., `hardware_blacklist`) | `camelCase`, `PascalCase` |
