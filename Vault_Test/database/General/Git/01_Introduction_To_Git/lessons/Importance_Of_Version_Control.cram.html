## Mental Model
Imagine you're working on a school project with your friends. You're all writing a story together, but each person is writing a different part. If you don't keep track of who wrote what and when, it can get very confusing. You might end up with multiple versions of the story, and it's hard to know which one is the most up-to-date. This is where version control comes in. Version control is like a superpower that helps you keep track of all the changes you make to your project over time. Git is a popular version control system that helps you manage your project files and track changes.

## What You Must Know
Version control is essential when working on projects, especially with teams. It allows you to:
* Keep track of changes made to your project files
* Collaborate with others without conflicts
* Revert back to previous versions if something goes wrong
* Experiment with new ideas without affecting the original work

## Common Mistakes
Many people think they can manage their projects without version control, only to realize later that it's much harder than they thought. Without version control, you might:
* Lose track of changes and end up with multiple versions of your project
* Have to redo work because you can't remember what changes you made
* Struggle to collaborate with others
