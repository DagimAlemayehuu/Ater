## Mental Model
To start using Git, you need to create a GitHub account. Think of GitHub like a library where you can store and share your books. Just like how you need a library card to borrow books, you need a GitHub account to store and share your code. When you create an account, you're essentially creating a profile that shows all your projects and code. This profile is like a portfolio that showcases your work to others.

## What You Must Know
To create a GitHub account, you'll need to go to the GitHub website and fill out a simple form with your email address, choose a username, and create a password. Make sure to choose a strong password and a username that's easy to remember. Once you've filled out the form, you'll receive a verification email to confirm your account. After verifying your account, you can start exploring GitHub and creating your first repository.

## Common Mistakes
One common mistake people make is not verifying their email address after signing up for GitHub. This can cause issues when trying to create a repository or collaborate with others. Make sure to check your email inbox and verify your account as soon as possible.
