# DEVELOPMENT WORKFLOWS

## 1. Feature Addition
1.  Add feature to `.system/state/GLOBAL_TASKS.md`.
2.  Adopt **Architect** role.
3.  Design in `.system/architecture/`.
4.  Adopt **Backend/Frontend** roles for implementation.
5.  Validate and update `.system/state/STATE.md`.

## 2. Bug Fixing
1.  Log bug in `.system/state/ERROR_REGISTRY.md`.
2.  Adopt **Detective** role.
3.  Fix and verify.
