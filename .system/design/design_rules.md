# UI/UX RULES
> **THEME:** Professional Dark Mode, Agency-Grade Aesthetics.

## 1. STACK
- **Tailwind CSS:** For all utility-first styling.
- **Shadcn UI:** For core components (buttons, dialogs, dropdowns).
- **Lucide React:** For consistent iconography.

## 2. PRINCIPLES
- **High-Signal Typography:** Inter or system-ui, minimal but bold.
- **Interactive Feedback:** Smooth transitions, hover states, and loading indicators.
- **Consistency:** Use the defined color palette and spacing system.

## 3. APP STRUCTURE
- **Navigation:** Left sidebar with clear icons.
- **Dashboard:** Grid-based layout for live metrics and status.
- **Modals:** Used for critical actions (Settings, Onboarding).
