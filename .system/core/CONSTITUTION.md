# THE CONSTITUTION
> **MANDATE:** This project is a professional, agency-grade Life Operating System.

## 1. QUALITY STANDARDS
- All code must be typed (TypeScript/Pydantic).
- All UI must use Tailwind CSS and Shadcn UI.
- All backend routes must have error handling and logging.

## 2. SECURITY
- No API keys in source code.
- Use encrypted storage for secrets.

## 3. ARCHITECTURE
- Offline-first.
- Local-first (Obsidian).
- Sidecar for AI orchestration.
